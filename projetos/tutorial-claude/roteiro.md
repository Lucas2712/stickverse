# Roteiro: tutorial do estúdio com Claude Code

> Sem roteiro escrito: texto tirado da transcrição da narração (Video_3.mp3); "Cloud" corrigido para "Claude".

Já imaginou ter um estúdio de inteligência artificial trabalhando com você? Um lugar onde seus projetos, ferramentas, referências e métodos de produção ficam organizados em um só lugar.

Hoje, vamos construir isso usando o Claude Code.

Primeiro, precisamos criar a estrutura do nosso estúdio. Uma pasta principal que vai funcionar como o cérebro de toda a operação. Dentro dela, vamos organizar nossas entradas, ferramentas, referências, projetos, biblioteca e métodos de trabalho.

Mas a estrutura sozinha não faz tudo. É aqui que entram as skills. Elas permitem ensinar ao Claude como executar tarefas específicas, seguindo processos e padrões de produção. Podemos adicionar ferramentas voltadas para motion design, edição e efeitos sonoros.

Agora, vamos conectar nosso projeto ao GitHub. Assim, conseguimos manter os arquivos organizados, preservar o trabalho e continuar de onde paramos.

Com a estrutura preparada, chegou a hora de configurar o ambiente e orientar o Claude sobre como nosso estúdio deve funcionar.

E aqui está a parte interessante. Em vez de explicar tudo novamente a cada projeto, o Claude passa a ter uma estrutura de trabalho organizada para consultar. Isso transforma uma simples conversa em um verdadeiro fluxo de produção.

E esse é apenas o começo. Na próxima parte, vamos começar a utilizar esse estúdio para produzir nossos próprios vídeos com inteligência artificial.
