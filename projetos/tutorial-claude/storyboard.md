# Storyboard: Tutorial: o estúdio de IA com Claude Code

> Aguardando aprovação. Nada é programado antes dela.

Tutorial de 74 s (narração intacta de 70,45 s + cartela de 3,5 s). Direção de arte exclusiva: apresentação de produto no estilo keynote, com tipografia sofisticada no espírito da Apple, janelas e terminal demonstrando cada etapa, 4 etapas numeradas e efeitos de interface. Sem música.

## Direção de arte

| | |
|---|---|
| Paleta | `#000000` preto keynote (aberturas e viradas) · `#F5F5F7` cinza-claro (as demonstrações) · `#1D1D1F` texto principal · `#86868B` texto secundário · `#7C5CFF` início do gradiente de destaque (violeta → rosa #FF4D8D → âmbar #FFB020) |
| Conceito | <b>Apresentação de produto (keynote).</b> O tutorial é contado como o lançamento de um produto: frases curtas e enormes em fundo preto, alternadas com demonstrações limpas em cinza-claro onde as janelas, o terminal e as pastas mostram cada etapa acontecendo. Palavras-chave em gradiente violeta → rosa → âmbar. |
| Tipografia | <b>Inter 4</b> com tamanho óptico (a versão Display nos títulos, a de texto no corpo): é a fonte livre mais próxima da SF Pro da Apple, com as mesmas proporções, peso semibold e espaçamento apertado nos títulos. Terminal e código em <b>JetBrains Mono</b>. |
| Por que não a fonte da Apple | a SF Pro é proprietária: a licença da Apple só permite usá-la em maquetes de interfaces para os sistemas da Apple, não em vídeos publicados. Usar o Inter evita esse risco com um resultado visual praticamente igual. |
| Sistema gráfico | janelas genéricas com sombra suave, terminal escuro, árvore de pastas, cards de skill com interruptores, linha de commits, painel de ajustes; selo de etapa «01 Estrutura» … «04 Ambiente»; cursor que clica; tudo sem logotipos (o GitHub aparece só como palavra). |
| Transições | assinatura deste vídeo: <b>zoom para dentro da janela</b> (a janela cresce e vira a cena seguinte), <b>passagem de foco</b> (desfoque de profundidade) e deslizes suaves de keynote |
| Áudio | narração intacta (sem aceleração e sem cortes: não há silêncio desnecessário, a maior pausa é de 0,52 s); <b>sem música</b>; efeitos de interface: teclas no terminal, cliques, interruptores, pops das pastas, whooshes suaves nas transições, um sino em cada etapa concluída |
| Diferente dos anteriores | nada de grade técnica azul, Martian Mono, duotone, laranja ou cards 3D com luz de borda; aqui é preto/cinza-claro com gradiente e tipografia de keynote |

## Pontos de atenção

- Fonte: a SF Pro (Apple) não pode ser usada em vídeo publicado por causa da licença. Uso o Inter 4 Display, a alternativa livre (licença OFL) mais próxima dela.
- A narração não foi alterada: sem aceleração e sem cortes. Não havia silêncio desnecessário; a maior pausa tem 0,52 s.
- Claude Code e GitHub aparecem só como texto; janelas, terminal e painéis são genéricos, sem copiar interfaces reais.
- Na cena 19, uso quadros dos nossos próprios vídeos (sem custo nem licença de terceiros).
- Sem imagens geradas e sem música: só narração e efeitos de interface reais (Real SFX).
